# 麦麦开袋台

**大家只选想吃的单品，点餐员比较买法；餐到了，先点数，再逐人递出。**

多人一起点麦当劳时，容易卡在三件事上：收齐每个人的选择、核对套餐是否更合适，以及收到餐后分清谁拿了什么。麦麦开袋台把这些步骤放进同一张共享餐桌，从单品意愿一直衔接到开袋清点。

面向办公室团餐、同事拼单和聚会的点餐员，以及使用电脑、平板或手机参与点餐的成员。这是基于麦当劳官方 MCP 的个人参赛原型，非麦当劳官方产品。

## 能做什么

- **成员只选单品**：按汉堡/主食、小吃、饮料、甜品等分类查找餐品，查看官方图片，用加减按钮提交意愿。
- **比较套餐与单品组合**：覆盖大家的单品需求，允许列出有额外餐品的便宜候选；通过官方整单核价排序，并保留纯单品基线。最低金额仅指本轮已核价候选，不承诺全局最低。
- **真实餐厅与地图核对**：读取门店、菜单和详情，显示地址与营业信息，打开高德地图搜索核对位置；缺失坐标不伪造落点或距离。
- **确认付款后接开袋台**：点餐员明确确认后才创建订单，本人在官方支付页付款，回查已支付且商品匹配后生成应收清单。
- **收餐与递餐分开操作**：分别记录应收、人工实收和已领取数量，显示短缺/超收，支持退回与撤销；额外餐品不擅自分给成员。
- **同局域网一起用**：成员可用有线或无线网络中的电脑、平板、手机打开邀请；组织者管理操作只允许来自服务电脑的回环连接。

## 先体验，不需要 Token

需要 Node.js 22 或更高版本。下载源码并解压，在项目根目录运行，无需安装依赖：

```sh
node prototype/group-server.mjs --demo --port 45076
```

打开终端给出的 `http://127.0.0.1:45076/group.html`，输入终端中本次生成的管理口令。

1. 选择“外带自取”→“我的收藏餐厅”，选择明确标记为合成的演示餐厅并建桌。
2. 复制邀请，在另一标签页打开；输入演示昵称，选择单品并提交。
3. 回到点餐员页面刷新，点击“截止收集并找买法”，比较候选并确认。
4. 仅在合成模式点击“模拟已付款（不收费）”，进入开袋台清点与递餐。

合成模式不连接麦当劳、不读取 MCP Token、不产生真实订单或费用。演示人名、地址、手机号和价格全部为测试用合成数据。

只想体验十二人收餐与递餐，可以运行：

```sh
node prototype/server.mjs
```

打开终端显示的本机地址。“演示少一份”是人工预设情境，不是图片识别或自动发现漏装。

## 接入自己的官方 MCP

在官方平台申请自己的 MCP Token。可从进程环境读取：

```sh
node --env-file=.env prototype/group-server.mjs --port 45075
```

先将 `.env.example` 复制成项目根目录 `.env`，仅在本机填写 `MCD_MCP_TOKEN`；地图 Key 可留空。也可明确使用自己创建的私人 Token 文件：

```sh
node prototype/group-server.mjs --token-file token.txt --port 45075
```

真实模式的门店查询、菜单读取和核价会连接官方服务。确认页的创建订单会产生真实订单，请本人核对后操作；支付由本人在官方页面完成。真实模式没有“模拟已付款”入口。本项目开发验证未创建或支付真实餐饮订单。

MCP 配置示例见 [mcp-config.example.json](mcp-config.example.json)，实际工具及调用流程见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。

## 局域网与 Windows

在可信局域网向其他设备分享时：

```sh
node prototype/group-server.mjs --demo --host 0.0.0.0 --port 45076
```

终端列出可用局域网地址，点餐员生成邀请后选择成员能访问的地址。Windows 已安装 Node.js 时，可双击 `prototype/启动合成演示.cmd`；真实模式入口为 `prototype/启动共享点餐.cmd`，它读取你自行准备的根目录 `token.txt`。

点餐员仍在服务电脑上通过 localhost 管理。网络隔离或防火墙可能影响其他设备访问；程序不改防火墙、不创建公网隧道。局域网邀请采用 HTTP，仅供可信网络原型使用，不是公网部署方案。

## 隐私设计

- 公开仓库只含源码、合成样例与说明，不含真实账户、订单、餐桌或开发会话。
- MCP Token 和可选地图 Key 只在服务端读取，不发给成员浏览器；配置示例只含空值或环境变量占位符。
- `.env`、`token.txt`、日志和运行数据目录不纳入版本控制。请勿把截图、真实 JSON、管理口令、邀请链接或支付链接提交到 Issue。
- 成员接口只返回其可见信息；配送地址仅在点餐员页面展示，手机号脱敏。原始电话、收件人和配送地址不写入持久化餐桌记录。
- 本机餐桌会保存成员昵称、意愿及必要订单关联信息，以便恢复清点；它们仍属于私有运行数据，不应上传仓库。
- 手工导入只提取商品与数量，丢弃订单号、电话、地址等字段，关闭导入窗口后清空原文。
- 官方商品图片由运行时官方响应提供，不随源码分发；请求限制为官方 HTTPS 图片域名。

## 验证与边界

```sh
node --test prototype/tests/*.test.mjs
```

当前82项测试通过，涵盖数量守恒、重复领取、导入、组合规划、权限、下单状态、地址校验及重启恢复；真实门店/菜单/详情和整单核价已做只读验证，官方图片与地图入口已在浏览器核对。

真实 GPS 定位、真实麦乐送核价、Windows 原生启动和另一台设备的实机连通尚未验证，本次按原型提交。地图定位需要自行配置高德 Web 服务 Key；没有 Key 时可以使用收藏或地标查询，浏览器不会因此自动索取位置。详情见 [VALIDATION.md](VALIDATION.md) 和 [原型操作说明](prototype/README.md)。

有界搜索、菜单缺项及官方可售状态可能影响候选；创建前重新核价。创建结果未知时不自动重试，需先核对官方订单。没有进行真实团餐节时实验，不宣称节省比例或保证获奖。
